Antes de começar

O piloto funciona no celular?

Sim. O piloto público pode ser aberto em celular. A agenda fica salva no navegador usado naquele aparelho.

Meus dados aparecem em outros aparelhos?

Não. O piloto atual salva os dados localmente neste navegador, sem conta ou sincronização entre dispositivos. Limpar os dados do navegador pode apagá-los. Use Backup para baixar uma cópia JSON.

E a demonstração, guarda meus pedidos?

Só neste navegador. Se você limpar os dados do navegador, eles somem. No próprio demo dá para baixar uma cópia de segurança.

Os pagamentos são confirmados automaticamente?

Não. Um valor informado só entra no recebido depois que você o confere.

Como recebo encomendas pelo link?

Entre na sua conta e abra Ajustes → Link de encomenda. Configure o nome da confeitaria, os produtos e o endereço do link, depois ative e compartilhe. Cada envio chega como Solicitação: você revisa antes de aceitar como orçamento ou pedido confirmado.

Como funciona o WhatsApp?

Depois de enviar a solicitação, a cliente pode tocar em “Avisar no WhatsApp”. O botão abre uma conversa com a confeitaria e o resumo preenchido; a cliente precisa tocar em enviar. Ele aparece se você configurou seu número. Você também pode copiar uma mensagem para responder à cliente. Não há envio automático nem integração com a API do WhatsApp.
