Antes de começar

O piloto funciona no celular?

Sim. O piloto público pode ser aberto em celular. A agenda fica salva no navegador usado naquele aparelho.

Meus dados aparecem em outros aparelhos?

Não. O piloto atual salva os dados localmente neste navegador, sem conta ou sincronização entre dispositivos. Limpar os dados do navegador pode apagá-los. Use Backup para baixar uma cópia JSON.

E a demonstração, guarda meus pedidos?

Só neste navegador. Se você limpar os dados do navegador, eles somem. No próprio demo dá para baixar uma cópia de segurança.

Os pagamentos são confirmados automaticamente?

Não. Um valor informado só entra no recebido depois que você o confere.

A Doce Agenda envia mensagens para minhas clientes?

Não. Você pode copiar o resumo do pedido para usar em outra conversa, mas o app não envia mensagens nem se conecta ao WhatsApp.
